# 3D関連の参考リンク

以下はリクエストされたリンクを分かりやすくまとめたリストです。

## 1. CloudCompare（クラウドコンペア）
* **リンク**: [https://www.cloudcompare.org](https://www.cloudcompare.org)
* **説明**: 3Dポイントクラウド（Point Cloud）およびメッシュ（Mesh）処理ソフトウェアです。オープンソースとして提供されており、3Dデータの分析、編集、視覚化に広く使用されています。

## 2. Sketchfab - Jaehwan.Lee（スケッチファブ ポートフォリオ）
* **リンク**: [https://sketchfab.com/Jaehwan.Lee](https://sketchfab.com/Jaehwan.Lee)
* **説明**: 3Dモデル共有プラットフォームであるSketchfab（スケッチファブ）のJaehwan.Leeさんのプロフィールページです。ウェブブラウザ上で直接3Dモデル作品を確認し、操作することができるポートフォリオです。
